`DataTable` es una tabla reutilizable y tipada que soporta dos modos de operación:

1. **Modo API (SWR)**: Pasa un `endpoint` y la tabla fetcha los datos automáticamente.
2. **Modo local**: Pasa directamente un array `data` ya obtenido.

Incluye: skeleton de carga, mensaje de estado vacío, paginación opcional y columnas con render personalizado.

## Importación

```tsx
import { DataTable } from '@/components/react/primary/DataTable';
import type { Column } from '@/components/react/primary/DataTable';
```

## Props

| Prop | Tipo | Descripción |
|------|------|-------------|
| `columns` | `Column<T>[]` | **Requerido.** Definición de columnas. |
| `endpoint` | `string` | URL del endpoint de la API. Se ignora si se pasa `data`. |
| `data` | `T[]` | Datos locales. Si se pasa, no se hace fetch. |
| `isLoading` | `boolean` | Fuerza el estado de carga desde afuera. |
| `className` | `string` | Clases adicionales para el contenedor. |
| `currentPage` | `number` | Página actual (para paginación). |
| `onPageChange` | `(page: number) => void` | Callback al cambiar de página. Si se pasa junto con datos de paginación del API, activa los controles de paginación. |

## Tipo `Column<T>`

```tsx
interface Column<T> {
  header: string;                        // Encabezado de la columna
  accessorKey?: keyof T;                 // Clave del objeto para mostrar el valor
  align?: "left" | "center" | "right";  // Alineación del contenido
  cell?: (item: T) => React.ReactNode;  // Render personalizado (override de accessorKey)
}
```

## Ejemplo: Modo API (fetching automático)

```tsx
interface Doctor {
  id: number;
  name: string;
  specialty: string;
}

const columns: Column<Doctor>[] = [
  { header: 'Nombre', accessorKey: 'name' },
  { header: 'Especialidad', accessorKey: 'specialty' },
  {
    header: 'Acciones',
    align: 'center',
    cell: (doctor) => (
      <Button label="Ver" size="sm" variant="ghost" onClick={() => navigate(`/doctors/${doctor.id}`)} />
    ),
  },
];

<DataTable
  endpoint="/api/doctors"
  columns={columns}
/>
```

## Ejemplo: Modo local (datos ya obtenidos)

```tsx
<DataTable
  endpoint=""          // Requerido por tipo, pero ignorado cuando se pasa data
  data={appointments}
  columns={columns}
/>
```

## Ejemplo: Con paginación

```tsx
const [page, setPage] = useState(1);

<DataTable
  endpoint="/api/sales"
  columns={salesColumns}
  currentPage={page}
  onPageChange={setPage}
/>
```

La paginación se muestra automáticamente en el footer si la API retorna un objeto con `pagination`:

```json
{
  "data": [...],
  "pagination": {
    "page": 1,
    "limit": 10,
    "total": 45,
    "totalPages": 5
  }
}
```

## Columnas con render personalizado

Usa `cell` para mostrar cualquier elemento React en lugar del valor crudo:

```tsx
{
  header: 'Estado',
  align: 'center',
  cell: (item) => (
    <Badge styles={{ bg: item.active ? 'bg-green-100' : 'bg-red-100' }}>
      {item.active ? 'Activo' : 'Inactivo'}
    </Badge>
  ),
}
```

<Aside type="note">
  El componente espera que la API retorne un **array directo** o un **objeto con propiedad `data`**. Ambos formatos son soportados automáticamente.
</Aside>

<Aside type="tip">
  Para estados de carga controlados externamente (ej: mientras procesas un filtro), pasa `isLoading={true}` y la tabla mostrará el skeleton independientemente del estado de SWR.
</Aside>
