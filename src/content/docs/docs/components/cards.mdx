## `ActionCard` — tarjeta clickeable

Usa `ActionCard` cuando **toda la tarjeta es clickeable**: navegar a un detalle, seleccionar un item, expandir información.

## Importación

```tsx
import ActionCard from '@/components/react/primary/ActionCard';
import StaticCard from '@/components/react/primary/StaticCard';
```

### Props de `ActionCard`

| Prop | Tipo | Descripción |
|------|------|-------------|
| `children` | `ReactNode` | **Requerido.** Contenido. |
| `onClick` | `() => void` | Handler del clic. |
| `className` | `string` | Clases adicionales. |

### Ejemplo

        <p className="text-xs text-cool-gray-50">Cédula: 1234567890</p>

    </div>
  </ActionCard>
</CodePreview>

## `StaticCard` — tarjeta informativa

Usa `StaticCard` para **agrupar y organizar información** sin acción directa.

### Props de `StaticCard`

| Prop | Tipo | Descripción |
|------|------|-------------|
| `children` | `ReactNode` | **Requerido.** Contenido. |
| `className` | `string` | Clases adicionales. |

### Ejemplo

<CodePreview code={`<StaticCard>
  <h3 className="text-sm font-semibold text-primary-900 mb-3">
    Información del paciente
  </h3>
  <p>Nombre: Juan Pérez</p>
  <p>Edad: 34 años</p>
  <p>Sangre: O+</p>
</StaticCard>`} client:load>
  <StaticCard className="w-full max-w-xs">
    <h3 className="text-sm font-semibold text-primary-900 mb-3">Información del paciente</h3>
    <div className="space-y-1 text-sm">
      <p><span className="text-cool-gray-50">Nombre:</span> <span className="text-primary-900 font-medium">Juan Pérez</span></p>
      <p><span className="text-cool-gray-50">Edad:</span> <span className="text-primary-900 font-medium">34 años</span></p>
      <p><span className="text-cool-gray-50">Sangre:</span> <span className="text-primary-900 font-medium">O+</span></p>
    </div>
  </StaticCard>
</CodePreview>

## Diferencias clave

| Característica | `ActionCard` | `StaticCard` |
|---|---|---|
| `cursor-pointer` | ✅ | ❌ |
| `onClick` | ✅ | ❌ |
| Borde del hover | `border-primary-500` | `border-primary-300` |
| Uso ideal | Navegar, seleccionar | Mostrar información |
