El sistema de modales está compuesto por dos componentes:

- **`Modal`**: La ventana modal en sí (controlada externamente).
- **`ModalTrigger`**: Un wrapper que encapsula el estado abierto/cerrado y provee un botón o trigger personalizado.

## Importación

```tsx
import { Modal } from '@/components/react/primary/Modal';
import { ModalTrigger } from '@/components/react/primary/ModalTrigger';
```

---

## `Modal`

Componente de bajo nivel. Úsalo cuando necesitas un control total sobre cuándo se abre y cierra.

### Props de `Modal`

| Prop | Tipo | Default | Descripción |
|------|------|---------|-------------|
| `isOpen` | `boolean` | — | **Requerido.** Controla la visibilidad del modal. |
| `onClose` | `() => void` | — | **Requerido.** Se llama al cerrar (clic en overlay o tecla ESC). |
| `title` | `string` | — | Si se proporciona, muestra un header con el título y un botón de cierre. |
| `children` | `ReactNode` | — | Contenido del cuerpo del modal. |

### Comportamiento

- Se renderiza en un **React Portal** sobre `document.body`, evitando problemas de `z-index`.
- Presionar **ESC** cierra el modal.
- Hacer **clic en el overlay** (fondo oscuro) cierra el modal.
- Bloquea el **scroll del body** mientras está abierto.
- Incluye atributos de accesibilidad (`role="dialog"`, `aria-modal`).

### Ejemplo básico

```tsx
const [open, setOpen] = useState(false);

<>
  <button onClick={() => setOpen(true)}>Abrir modal</button>

  <Modal
    isOpen={open}
    onClose={() => setOpen(false)}
    title="Confirmar acción"
  >
    <p>¿Estás seguro de que deseas continuar?</p>
    <div className="flex justify-end gap-2 mt-4">
      <Button label="Cancelar" variant="secondary" onClick={() => setOpen(false)} />
      <Button label="Confirmar" onClick={handleConfirm} />
    </div>
  </Modal>
</>
```

## `ModalTrigger`

Wrapper conveniente que maneja el estado `isOpen` internamente. Ideal para la mayoría de los casos de uso donde no necesitas controlar el modal desde afuera.

### Props de `ModalTrigger`

| Prop | Tipo | Default | Descripción |
|------|------|---------|-------------|
| `modalTitle` | `string` | — | **Requerido.** Título del modal. |
| `buttonLabel` | `string` | `"Open Check definition"` | Texto del botón trigger por defecto. |
| `buttonTheme` | `variant` | `"primary"` | Variante visual del botón trigger. |
| `children` | `ReactNode \| ((props: { close: () => void }) => ReactNode)` | — | Contenido del modal. Puede ser una función que recibe `{ close }`. |
| `trigger` | `ReactNode` | — | Elemento personalizado como trigger (reemplaza al botón por defecto). |

### Ejemplo simple

```tsx
<ModalTrigger
  buttonLabel="Ver historial"
  modalTitle="Historial del paciente"
>
  <p>Aquí va el contenido del historial...</p>
</ModalTrigger>
```

### Cerrar el modal desde dentro del contenido

Usa la forma de función en `children` para acceder a `close`:

```tsx
<ModalTrigger
  buttonLabel="Nueva cita"
  modalTitle="Agendar cita"
  buttonTheme="secondary"
>
  {({ close }) => (
    <form onSubmit={(e) => { e.preventDefault(); handleSubmit(); close(); }}>
      <Field name="fecha" label="Fecha" type="date" ... />
      <Button label="Guardar" type="submit" adaptive />
    </form>
  )}
</ModalTrigger>
```

### Trigger personalizado (sin botón)

Usa la prop `trigger` para usar cualquier elemento como disparador:

```tsx
<ModalTrigger
  modalTitle="Detalle de turno"
  trigger={
    <div className="flex items-center gap-2 p-3 rounded-lg hover:bg-primary-200 cursor-pointer">
      <span className="font-medium">Dr. García</span>
      <Badge>Ver detalle</Badge>
    </div>
  }
>
  <p>Información del turno...</p>
</ModalTrigger>
```

<Aside type="tip">
  Usa `ModalTrigger` por defecto. Recurre a `Modal` directamente solo cuando necesites sincronizar el estado del modal con lógica externa (ej: abrir desde una tabla de datos).
</Aside>
