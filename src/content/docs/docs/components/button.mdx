El componente `Button` es el botón estándar del sistema. Soporta 4 variantes visuales, 4 tamaños, estado de carga con spinner y está construido con `forwardRef` para integrarse con bibliotecas de formularios.

## Importación

```tsx
import { Button, ButtonTheme } from '@/components/react/primary/Button';
```

## Props

| Prop | Tipo | Default | Descripción |
|------|------|---------|-------------|
| `label` | `string` | — | **Requerido.** Texto del botón (se usa si no se pasan `children`). |
| `variant` | `"primary" \| "secondary" \| "ghost" \| "danger-ghost"` | `"primary"` | Estilo visual del botón. |
| `size` | `"default" \| "sm" \| "lg" \| "icon"` | `"default"` | Tamaño del botón. |
| `loading` | `boolean` | `false` | Si es `true`, muestra un spinner y bloquea interacción. |
| `adaptive` | `boolean` | `false` | Si es `true`, el botón ocupa el 100% del ancho (`w-full`). |
| `disabled` | `boolean` | — | Deshabilita el botón. Se combina automáticamente con `loading`. |
| `children` | `ReactNode` | — | Contenido alternativo. Si se pasa, reemplaza al `label`. |

También acepta todos los atributos nativos de `<button>` (`onClick`, `type`, `form`, etc.).

## Constante `ButtonTheme`

Para evitar strings literales, usa la constante exportada:

```tsx
import { Button, ButtonTheme } from '@/components/react/primary/Button';

<Button label="Enviar"    variant={ButtonTheme.PRIMARY} />
<Button label="Cancelar"  variant={ButtonTheme.SECONDARY} />
<Button label="Eliminar"  variant={ButtonTheme.DANGER_GHOST} />
```

<Aside type="tip">
  El componente usa `forwardRef`, por lo que puedes pasarle una `ref` directamente para integrarlo con React Hook Form o para controlar el foco programáticamente.
</Aside>
