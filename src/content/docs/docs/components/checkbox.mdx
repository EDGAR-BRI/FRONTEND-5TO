`CheckBox` ofrece dos variantes: el checkbox tradicional y un switch tipo toggle animado.

## Importación

```tsx
import { CheckBox } from '@/components/react/primary/CheckBox';
```

## Props

| Prop | Tipo | Default | Descripción |
|------|------|---------|-------------|
| `label` | `string` | — | **Requerido.** Texto visible. |
| `checked` | `boolean` | — | Estado controlado. |
| `onChange` | `(e) => void` | — | Handler de cambio. |
| `name` | `string` | — | Nombre del campo HTML. |
| `variant` | `"checkbox" \| "switch"` | `"checkbox"` | Variante visual. |
