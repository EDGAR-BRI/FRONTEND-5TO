## Spinner

Indicador de carga circular animado. Usado internamente por `Button` cuando `loading={true}`, pero también disponible para uso independiente.

### Importación

```tsx
import { Spinner } from '@/components/react/primary/Spinner';
```

### Props

| Prop | Tipo | Default | Descripción |
|------|------|---------|-------------|
| `className` | `string` | `""` | Clases para controlar el tamaño y color. |

## Tooltip

Muestra un globo de información al hacer hover sobre un ícono `?`.

### Importación

```tsx
import { Tooltip } from '@/components/react/primary/Tooltip';
```

### Props

| Prop | Tipo | Default | Descripción |
|------|------|---------|-------------|
| `text` | `string` | — | **Requerido.** Texto del tooltip. |
| `position` | `"top" \| "bottom" \| "left" \| "right"` | `"top"` | Posición del globo. |

### Ejemplo junto a un label

<CodePreview code={`<div className="flex items-center gap-1">
  <label>Cédula</label>
  <Tooltip text="El número debe tener 10 dígitos, sin guiones." />
</div>

<div className="flex items-center gap-1">
  <label>RFC</label>
  <Tooltip text="Ingresa el RFC con homoclave, sin espacios." />
</div>`} client:load>
  <div className="flex items-center gap-1 text-sm text-primary-900">
    <label>Cédula</label>
    <Tooltip text="El número debe tener 10 dígitos, sin guiones." />
  </div>
  <div className="flex items-center gap-1 text-sm text-primary-900">
    <label>RFC</label>
    <Tooltip text="Ingresa el RFC con homoclave, sin espacios." />
  </div>
</CodePreview>
