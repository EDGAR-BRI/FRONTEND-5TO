`Field` es el componente de entrada de datos principal del sistema. Unifica en un solo componente todos los tipos de input más comunes, con estilos consistentes y funcionalidades extra como mostrar/ocultar contraseña, validación de números decimales y un calendario custom (powered by `react-day-picker`).

## Importación

```tsx
import { Field } from '@/components/react/primary/Field';
```

## Props

| Prop | Tipo | Default | Descripción |
|------|------|---------|-------------|
| `name` | `string` | — | **Requerido.** Nombre del campo (usado en `id` y `name` del input). |
| `label` | `string` | — | Etiqueta visible sobre el campo. |
| `type` | `"text" \| "email" \| "password" \| "number" \| "date" \| "radio"` | `"text"` | Tipo de input. |
| `value` | `string \| number` | — | Valor controlado. |
| `onChange` | `(e: ChangeEvent<HTMLInputElement>) => void` | — | Handler de cambio. |
| `placeholder` | `string` | — | Texto de placeholder. |
| `required` | `boolean` | — | Marca el campo como requerido. |
| `disabled` | `boolean` | — | Deshabilita el campo. |
| `variant` | `"primary" \| "secondary" \| "tertiary"` | `"primary"` | Controla el color de fondo del input. |
| `tooltip` | `string` | — | Muestra un ícono `?` con tooltip al hover. |
| `showTogglePassword` | `boolean` | `false` | Para `type="password"`: muestra botón de ojo para ver/ocultar. |
| `allowNegative` | `boolean` | `false` | Para `type="number"`: permite valores negativos. |
| `useNativeDatePicker` | `boolean` | `true` | Para `type="date"`: si es `false`, usa el calendario custom. |
| `options` | `{ label: string; value: string \| number }[]` | — | Para `type="radio"`: lista de opciones. |
| `onEnter` | `() => void` | — | Se llama al presionar `Enter`. |
| `step` | `string \| number` | — | Para `type="number"`: incremento del valor. |

También acepta todos los atributos nativos de `<input>`.

## Ejemplos de uso

### Input de texto simple

<CodePreview code={`const [nombre, setNombre] = useState('');

<Field
  name="nombre"
  label="Nombre del paciente"

  value={nombre}
  onChange={(e) => setNombre(e.target.value)}

### Fecha con calendario custom

Cuando `useNativeDatePicker={false}`, se muestra un popover con un calendario visual estilizado.

<CodePreview code={`<Field
  name="fecha_cita"
  label="Fecha de la cita"
  type="date"
  useNativeDatePicker={false}
  value={fecha}         // Formato ISO: "2024-08-15"
  onChange={(e) => setFecha(e.target.value)}
/>`} client:load>
  <div className="w-full h-96">
    <Field
      name="fecha_cita_demo"
      label="Fecha de la cita"
      type="date"
      useNativeDatePicker={false}
      defaultValue=""
    />
  </div>
</CodePreview>

<Aside type="note">
  El valor siempre se emite en formato ISO (`yyyy-MM-dd`) aunque el calendario muestre la fecha en formato `dd/MM/yyyy`.
</Aside>
