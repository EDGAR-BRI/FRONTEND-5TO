`StatsCard` muestra una métrica numérica destacada junto con información contextual como tendencia (↑/↓), ícono y subtexto. Tiene dos variantes de layout: `default` (más grande, para grids de stats) y `compact` (horizontal, para listas o filas).

## Importación

```tsx
import { StatsCard } from '@/components/react/primary/StatsCard';
```

## Props

| Prop | Tipo | Default | Descripción |
|------|------|---------|-------------|
| `title` | `string` | — | **Requerido.** Etiqueta de la métrica. |
| `value` | `string \| number` | — | **Requerido.** El valor principal a destacar. |
| `icon` | `ReactNode` | — | Ícono (SVG o componente) que se muestra en la esquina. |
| `color` | `"primary" \| "success" \| "danger" \| "warning"` | `"primary"` | Color del fondo del ícono. |
| `variant` | `"default" \| "compact"` | `"default"` | Layout de la tarjeta. |
| `trend` | `string` | — | Texto del indicador de tendencia. Ej: `"12%"`. Requiere que `subText` esté vacío. |
| `trendUp` | `boolean` | — | Si es `true`, la tendencia se muestra en verde (↑). Si es `false`, en rojo (↓). |
| `trendLabel` | `string` | `"vs mes anterior"` | Texto auxiliar junto al trend. |
| `subText` | `string` | — | Texto informativo alternativo al trend. Ej: `"3 activos hoy"`. |
| `subTextClass` | `string` | — | Clases Tailwind para personalizar el color del subtexto. |
