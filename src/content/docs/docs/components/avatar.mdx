`Avatar` es un componente compuesto (compound component) formado por tres piezas: el contenedor `Avatar`, la imagen `AvatarImage` y el fallback `AvatarFallback` para cuando no hay imagen disponible.

## Importación

```tsx
import { Avatar, AvatarImage, AvatarFallback } from '@/components/react/primary/Avatar';
```

## Componentes

### `Avatar`

Contenedor circular. Acepta todos los atributos de un `<div>`.

| Prop | Tipo | Descripción |
|------|------|-------------|
| `className` | `string` | Clases adicionales (ej: para controlar el tamaño). |

### `AvatarImage`

Imagen que ocupa el 100% del contenedor con `object-cover`.

| Prop | Tipo | Descripción |
|------|------|-------------|
| `src` | `string` | URL de la imagen. **Requerido.** |
| `alt` | `string` | Texto alternativo. **Requerido.** |
| `className` | `string` | Clases adicionales. |

### `AvatarFallback`

Contenido que se muestra cuando no hay imagen (ej: iniciales o ícono).

| Prop | Tipo | Descripción |
|------|------|-------------|
| `className` | `string` | Clases adicionales (ej: color de fondo, color de texto). |
| `children` | `ReactNode` | Contenido del fallback. |

### Con imagen de perfil

### Con iniciales como fallback

<CodePreview code={`const getInitials = (name: string) =>
  name.split(' ').map(n => n[0]).join('').toUpperCase().slice(0, 2);

<Avatar className="w-10 h-10">
  <AvatarFallback className="bg-primary-300 text-primary-900 text-sm font-semibold">
    {getInitials(doctor.name)}
  </AvatarFallback>
</Avatar>`} client:load>
  <Avatar className="w-10 h-10">
    <AvatarFallback className="bg-primary-300 text-primary-900 text-sm font-semibold">
      JP
    </AvatarFallback>
  </Avatar>
</CodePreview>

### Tamaños

El tamaño se controla con clases en el `Avatar`:

<CodePreview code={`{/* Pequeño */}
<Avatar className="w-8 h-8">
  <AvatarFallback>SM</AvatarFallback>
</Avatar>

{/* Mediano (default recomendado) */}
<Avatar className="w-10 h-10">
  <AvatarFallback>MD</AvatarFallback>
</Avatar>

{/* Grande */}
<Avatar className="w-16 h-16">
  <AvatarFallback>LG</AvatarFallback>
</Avatar>`} client:load>
  <div className="flex gap-4 items-end">
    <Avatar className="w-8 h-8">
      <AvatarFallback className="bg-primary-100 text-xs text-primary-900 border border-primary-200">SM</AvatarFallback>
    </Avatar>
    <Avatar className="w-10 h-10">
       <AvatarFallback className="bg-primary-100 text-sm text-primary-900 border border-primary-200">MD</AvatarFallback>
    </Avatar>
    <Avatar className="w-16 h-16">
       <AvatarFallback className="bg-primary-100 text-xl text-primary-900 border border-primary-200">LG</AvatarFallback>
    </Avatar>
  </div>
</CodePreview>
